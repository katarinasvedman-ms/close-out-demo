# Foundry agent development

This project was built with the microsoft-foundry skill. Before working on or
answering questions about foundry agents, read the microsoft-foundry skill first.

Follow `.github/copilot-instructions.md` and the authoritative design documents.
Use Foundry prompt agents and native IQ, not a hosted agent or application container.
The local synthetic-facts client is a test harness, not a deployed service or the
Dataverse process owner. Live Fabric MCP integration remains a separate gate.
